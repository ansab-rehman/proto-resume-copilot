# Senior Full-Stack Engineer

We're a 40-person B2B SaaS company building workflow tools for operations teams. You'll own
features end to end, from the database to the UI, and help raise the bar for the team.

## What you'll do
- Design and ship product features across our Python backend and React frontend
- Own services in production on AWS: deploys, monitoring, incident follow-ups
- Review code and mentor engineers

## Requirements
- 5+ years of professional software engineering experience
- Strong backend experience with Python (FastAPI or Django)
- Production experience building frontends with React and TypeScript
- Solid SQL and relational database design (PostgreSQL preferred)
- Hands-on experience deploying and operating services on AWS

## Nice to have
- Docker and Kubernetes
- CI/CD pipelines (e.g. GitHub Actions)
- Experience mentoring or leading other engineers
- Integrating LLM APIs into products

We offer remote-first work, a learning budget and flexible hours.
